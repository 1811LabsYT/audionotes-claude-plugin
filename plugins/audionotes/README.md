# Audionotes for Claude and Hermes Agent

Find and read your Audionotes recordings, transcripts and summaries from Claude
or Hermes Agent.
Ask questions such as "What did we decide about pricing in last week's call?"
and Claude searches your notes, reads the relevant parts and cites the notes it
used.

## What it can do

The plugin connects Claude to the Audionotes server at
`https://api.audionotes.app/mcp`. It has four read-only tools:

| Tool | What it does |
| --- | --- |
| Search notes (`search_notes`) | Searches your notes for relevant passages. |
| List notes (`list_notes`) | Lists your notes, filtered by folder, date or type. |
| List folders (`list_folders`) | Lists your folders. |
| Get note (`get_note`) | Reads a note's title, summary or transcript sections. |

It cannot create, edit, delete or share notes.

## Requirements

You need a paid Audionotes account. Sign up at
[audionotes.app](https://www.audionotes.app).

## Connect

1. Install the plugin in Claude.
2. When Claude asks you to connect Audionotes, sign in to Audionotes in your
   browser.
3. Review the consent page and approve read access (`notes:read`).

Access covers every note you own, including notes you add later.

## Hermes Agent

This folder is also an Agent Plugins package for Hermes Agent: `plugin.json`,
`mcp.json` and the `retrieve-notes` skill. You need Hermes Agent 0.21.6 or
newer, and Node.js 20.18.1 or newer with `npx` on your `PATH`.

```sh
hermes plugins install audionotes
hermes plugins enable audionotes
```

Start a new session and sign in to Audionotes when your browser opens. Before
you install, note that:

- Every tool call goes to the hosted Audionotes server at
  `api.audionotes.app`. Note content that matches your request enters the
  session and is sent to your model provider.
- Sign-in runs the pinned `mcp-remote@0.1.49` through `npx`. On first use it
  opens your browser and a local callback port, and it stores OAuth tokens
  under `~/.mcp-auth`.
- The package marks the server untrusted. All four tools are read-only, so
  Hermes runs them without asking.

## Your data

- Search queries are processed by Audionotes' search service.
- Note content that matches your request is sent to Claude, which means it is
  sent to Anthropic. Your notes may contain private information, so connect
  only if that is acceptable to you.
- Search results can be incomplete. Listing and reading notes do not depend on
  search.
- Summaries are generated by Audionotes and are labeled separately from source
  transcripts.

## Disconnect

Go to Audionotes **Settings → Integrations** and disconnect Claude. Claude then
cannot read your notes. Disconnecting does not remove content Claude has
already received.
